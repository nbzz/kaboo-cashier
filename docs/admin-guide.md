# 系統管理指南（單設備離線版）

## 1) 日常使用

1. 打開系統後進入「快速記賬」。
2. 優先在同一台設備操作，避免資料分散。
3. 每日營業中至少保持一次聯網，確保當天自動備份可發送。

## 2) 數據同步

- 進入「數據同步」頁可設定本機記賬人資訊。
- 系統會每日首次聯網自動同步備份。
- 若網絡或郵件服務失敗，會每 30 分鐘重試。

## 3) 安全建議

- SMTP 密碼放在 `.env.local`，不要提交到 Git。
- 建議使用郵箱專用 SMTP 授權碼，不使用主密碼。
- 每週至少手動導出一次流水 CSV 做額外離線備份。

## 4) 故障排查

- 打不開頁面：先確認 `npm run dev` 是否啟動。
- 備份未到郵箱：檢查 SMTP 配置、垃圾箱、收件規則。
- 數據異常：優先用最近備份 JSON 或 CSV 做恢復。
